# Introduction

This document describes the rules and recommendations for the implementation of localization resources.

## General conventions

- Use of a designer class generated by .NET tooling that fetches localized text automatically

  > The origin of this approach was discussed in issue [425](https://gitlab.i40.ifm-datalink.net/acx/vicione/suite-apps/cluster-management/cluster-editor/-/issues/425).

- Resource keys should use [`PascalCase`](https://en.wikipedia.org/wiki/Camel_case) notation as code generated from resource keys should adhere to [C# naming conventions](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/coding-style/identifier-names#naming-conventions).

- Resource keys should use English wording

## Common localization

- Localized text that can be shared with other application parts should be stored in one of the following resource files:

    | Resource file | Description |
    |-|-|
    | [`CommonPatterns`](../src/ViciOne.Ui.Localization/Resources/CommonPatterns.Designer.cs) | Common patterns with placeholders like `{0} & {1}` that can be replaced to something like `Date & Time` |
    | [`CommonPhrases`](../src/ViciOne.Ui.Localization/Resources/CommonPhrases.Designer.cs) | Common phrases like `An unknown error occurred.` |
    | [`CommonVocabulary`](../src/ViciOne.Ui.Localization/Resources/CommonVocabulary.Designer.cs) | Common vocabulary like `Yes` or `No` |
    | [`LibraryManagement`](../src/ViciOne.Ui.Localization/Resources/LibraryManagement.Designer.cs) | Phrases like `Pending installation of version` that are used in context of library management |
    | [`ProductNames`](../src/ViciOne.Ui.Localization/Resources/ProductNames.Designer.cs) | Product names like `moneo \| automation` |
    | [`TechnicalAcronyms`](../src/ViciOne.Ui.Localization/Resources/TechnicalAcronyms.Designer.cs) | Technical [acronyms](https://de.wikipedia.org/wiki/Akronym) like `TCP` |
    | [`TechnicalTerms`](../src/ViciOne.Ui.Localization/Resources/TechnicalTerms.Designer.cs) | Technical terms like `Data port` |
    | [`UserActions`](../src/ViciOne.Ui.Localization/Resources/UserActions.Designer.cs) | User actions like `Renew {0}` |
    | [`ValidationMessages`](../src/ViciOne.Ui.Localization/Resources/ValidationMessages.Designer.cs) | Validation messages like `Field is required.` |

- Resource keys for pluralized terms should end with suffix `Plural` to differentiate from the singular term as some english words in the pluralized form do not end with `s`

- Resource keys for abbreviations should end with suffix `Abbreviation`

### Common vocabulary specific rules

- Resource keys for verbs should end with suffix `Verb` when the resource key without the suffix would be ambiguous
